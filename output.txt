# Hardened vs Non-Hardened
Hardened keys: cannot derive child private keys from public key, more secure.
Non-Hardened keys: child keys derivable from public key, useful for watch-only wallets.

# Deterministic vs Non-Deterministic
Deterministic wallets: generate addresses from single seed, easier backup and recovery.
Non-Deterministic wallets: generate addresses randomly, backup each key individually.
